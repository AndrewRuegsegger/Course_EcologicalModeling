Roberts CP, Donovan VM, Wonkka CL, Powell L, Allen CR, Angeler DG, Wedin D, Twidwell D. 2018. Fire legacies in eastern ponderosa pine. Ecology and Evolution.

dataset: PlotLocations_FortRob.csv
ID = sampling plot numeric identifier
Burn = Wildfire surveyed. Only "Fort Rob" data provided for most files.
Class = burn severity class derived from Monitoring Trends in Burn Severity database
Latitude = latitude coordinate
Longitude = longitude coordinate
Changes = notes 

dataset: PineRidge_CWD.csv
Plot Number = sampling plot numeric identifier
Fire Type = burn severity class derived from Monitoring Trends in Burn Severity database
%LineCover = percent of 30 m transect that coarse wood debris intersected

dataset: PCQ.density.csv
live.dead = indicates whether tree was alive or dead
cover.burn = burn severity class derived from Monitoring Trends in Burn Severity database
site = sampling plot identifier with burn severity class.
mean.dist = average distance (m) of four live/dead trees measured according to the point center quarter method.
density = trees / ha

dataset: PineRidge_BirdVeg_ShrubCover.csv
date = date measured
site = sampling plot identifier with burn severity class.
plot = center, north, south, east, west plots
species = understory woody plant species four letter identifier. First two of genus, first two of species.
percentage.cover = percent of plot covered by each species

dataset: PineRidge_BirdData.csv
date = date measured
visit.num = first or second visit (each site was visited twice to capture bird community composition)
cover = forest or grass
burn = burn severity class derived from Monitoring Trends in Burn Severity database
point = sampling plot identifier
lat = latitude coordinate
lon = longitude coordinate
start = start time of point count survey
end = end time of point count survey
wind = wind speed by Beaufort Scale
weather = weather description
species = American Ornithological Union species identifier
a.v = audio detection or visual detection
dist = distance (m) classes. 1 = 0 - 30 m, 2 = 30 - 50 m, 3 = 50 - 100 m, 4 = 100 - all
in.flight = binomial variable 1 = fly over, 0 = not fly over
